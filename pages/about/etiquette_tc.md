# 參典禮儀與彈幕規範

本紀念堂為虛擬之莊嚴場所，請參典者依循以下禮節與操作指引：
* **致敬禮儀**：進入本網站時，請先向國父遺像行三鞠躬禮，以表達對革命先烈之崇高敬意。
* **奏樂儀式**：點擊畫面中央之國父遺像，即可播放紀念樂曲。
* **彈幕留言**：參典者可點擊底部導覽列之「留言」按鈕發表致意，您的留言將以彈幕形式於畫面上方優雅飄過。若需暫停或隱藏彈幕，可點擊畫面右下角之「彈幕」開關按鈕。
  * **【彈幕禮儀】**
  * 1. 請保持理性與尊重。
  * 2. 勿發表謾罵、政治煽動或攻擊言論。
  * 3. 共同維護紀念堂的莊嚴。
  * 4. 請自覺遵守您所在地的相關法律法規，發言需承擔相應的法律責任。
